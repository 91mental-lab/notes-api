# Notes API
## Описание

Notes API - это бэкенд-сервис для создания, хранения и управления личными заметками с акцентом на безопасность. API позволяет пользователям регистрироваться, входить в систему, а затем создавать, читать, обновлять и удалять свои зашифрованные заметки. Пароли пользователей хешируются, а сами заметки хранятся в зашифрованном виде.

## Особенности

*   **Аутентификация пользователей:** Регистрация, вход, Refresh токены.
*   **Безопасность паролей:** Хеширование паролей с использованием bcrypt.
*   **Шифрование заметок:** Заметки шифруются перед сохранением в базе данных и расшифровываются при чтении.
*   **Управление заметками:** CRUD операции (Создать, Прочитать, Обновить, Удалить) для заметок пользователя.
*   **Автоматическая документация API:** Интеграция Swagger UI (OpenAPI) и ReDoc.
*   **Валидация данных:** Использование Pydantic для строгой валидации входящих и исходящих данных.
*   **Асинхронные операции:** Построено на FastAPI для высокопроизводительных асинхронных операций.

## Используемые Технологии

*   **Python 3.13**
*   **FastAPI** - Веб-фреймворк для создания API.
*   **SQLAlchemy** - ORM для работы с базой данных (PostgreSQL/SQLite).
*   **Alembic** - Инструмент для миграций базы данных.
*   **Passlib (Bcrypt)** - Для хеширования паролей.
*   **PyJWT** - Для работы с JSON Web Tokens.
*   **python-multipart** - Для работы с формами.
*   **python-dotenv** - Для управления переменными окружения.
*   **uvicorn** - ASGI-сервер для запуска FastAPI приложения.
*   **cryptography** - Для шифрования/дешифрования заметок.

## Предварительные Требования

Перед запуском проекта убедитесь, что у вас установлено:

*   Python 3.9 или выше
*   pip (менеджер пакетов Python)

## Установка

1.  **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/your-username/secure-notes-api.git
    cd secure-notes-api
    ```

2.  **Создайте виртуальное окружение (рекомендуется):**

    ```bash
    python -m venv venv
    source venv/bin/activate  # Для Linux/macOS
    # venv\Scripts\activate   # Для Windows
    ```

3.  **Установите зависимости:**

    ```bash
    pip install -r requirements.txt
    ```
